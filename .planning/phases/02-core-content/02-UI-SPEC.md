# Phase 2 — UI Design Contract

> Visual and interaction contract for Phase 2: Core Content.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This phase fills all five content sections (hero, projects, about, timeline, contact)
> against the validated Phase 1 foundation. All design tokens are inherited from
> css/tokens.css — no new tokens are introduced unless explicitly noted.
>
> **Typography note:** The actual codebase uses Space Grotesk (display) + Inter (body),
> reflecting commit "feat(design): switch typography to Space Grotesk + Inter".
> The Phase 1 UI-SPEC.md references Cormorant Garamond + Lora — treat css/tokens.css
> as authoritative. This spec is written against the actual codebase state.

## Spacing Scale

Inherited from Phase 1 tokens — no new values introduced.

| Token        | Value | Phase 2 Usage                                                         |
|--------------|-------|-----------------------------------------------------------------------|
| `--space-xs` | 4px   | Tech pill horizontal padding (inner), gap between pill rows           |
| `--space-sm` | 8px   | Gap between pills in a row, card inner vertical gap between elements  |
| `--space-md` | 16px  | Card internal padding, timeline bullet gap, about label/tag row gap   |
| `--space-lg` | 24px  | Card padding (all sides), gap between CTA buttons (dual marketplace)  |
| `--space-xl` | 32px  | Gap between project cards (mobile), hero element stacking gap         |
| `--space-2xl`| 48px  | Section padding-block on mobile (inherited from layout.css)           |
| `--space-3xl`| 64px  | Section padding-block on desktop (inherited from layout.css)          |
| `--space-4xl`| 96px  | Not used in Phase 2 content components                                |

Exceptions:
- Touch targets on CTA buttons and marketplace links: minimum 44px height (WCAG 2.5.5 AAA), achieved via padding, not a spacing token.
- Timeline dot diameter: 12px (not on the 8-pt grid — intentional small decorative element).
- Timeline left gutter: 20px (half of --space-xl, positions the dot on the accent line).

## Section Layout Contracts

### 1. Hero Section (`#hero`)

**Goal:** Visitor reads name, title, tagline, and CTA without scrolling (HERO-01, HERO-02).

| Property              | Value                                                                              |
|-----------------------|------------------------------------------------------------------------------------|
| Layout                | `display: flex; flex-direction: column; align-items: center; justify-content: center; text-align: center` |
| Min-height            | `calc(100vh - var(--nav-height))` — fills first viewport below sticky nav         |
| Element stack order   | H1 → subtitle → tagline → CTA button                                              |
| Gap between H1 and subtitle | `--space-sm` (8px)                                                        |
| Gap between subtitle and tagline | `--space-md` (16px)                                                  |
| Gap between tagline and CTA | `--space-xl` (32px)                                                      |
| Max-width of hero text block | 640px (centered, prevents very wide line lengths on large screens)       |
| Responsive: mobile   | Same centered column; H1 may reflow to 2 lines if viewport < 360px                |
| Responsive: tablet 768px | Same column, same centered; padding-inline inherited from `main` (48px)    |
| Responsive: desktop 1024px | Same column; more breathing room from section padding-block (64px)        |

**H1 — "Riccardo Corsi":**
- Font: `--font-family-display` (Space Grotesk), `--font-size-display` (3rem / 48px), weight 400, `--line-height-tight` (1.1)
- Color: `--color-text-primary`
- No letter-spacing adjustment

**Subtitle — "Software Developer":**
- Font: `--font-family-display` (Space Grotesk), `--font-size-heading` (1.5rem / 24px), weight 400, `--line-height-heading` (1.3)
- Color: `--color-text-secondary`
- Element: `<p>` with `.hero__subtitle` class

**Tagline:**
- Font: `--font-family-body` (Inter), `--font-size-body` (1rem / 16px), weight 400, `--line-height-body` (1.6)
- Color: `--color-text-secondary`
- Element: `<p>` with `.hero__tagline` class
- Max-width: 480px (narrower than headline block — keeps tagline scannable)

**CTA Button — "View my work ↓":**
- Element: `<a href="#projects" class="btn btn--primary">`
- Background: `--color-accent` (`#8B6914`)
- Text: white (`#FFFFFF`) — confirmed contrast on amber-gold: ~4.6:1 (passes AA)
- Font: `--font-family-body` (Inter), `--font-size-body` (1rem), weight 400
- Padding: `--space-md` vertical (16px) + `--space-xl` horizontal (32px)
- Min-height: 44px (touch target)
- Border-radius: 2px (editorial, not pill-shaped)
- Border: none
- Hover: `opacity: 0.85; transform: translateY(-1px)` — CSS transition 200ms ease
- No box-shadow (flat style consistent with editorial aesthetic)

### 2. Projects Section (`#projects`)

**Goal:** 3 project cards, data from `data/projects.json`, each with problem/highlight/outcome copy + tech pills + marketplace CTA(s) (PROJ-01, PROJ-02, PROJ-03).

**Section heading:** `<h2>Projects</h2>` — 1.5rem, Space Grotesk 600, `--color-text-primary`
**Heading margin-bottom:** `--space-xl` (32px) before card grid

**Card Grid:**

| Property              | Value                                                                       |
|-----------------------|-----------------------------------------------------------------------------|
| Layout                | CSS Grid, `grid-template-columns: 1fr` (mobile)                            |
| Gap between cards     | `--space-xl` (32px) on mobile                                              |
| Tablet 768px          | `grid-template-columns: repeat(2, 1fr)`; gap `--space-lg` (24px)           |
| Desktop 1024px        | `grid-template-columns: repeat(3, 1fr)` if 3 cards; gap `--space-lg` (24px)|
| Fallback (1-2 cards)  | Cards stretch to fill available columns; max card width: 480px centered     |

**Project Card Component (`.project-card`):**

| Property              | Value                                                                       |
|-----------------------|-----------------------------------------------------------------------------|
| Background            | `--color-bg-secondary` (`#EDE8DF`)                                         |
| Border                | `1px solid color-mix(in srgb, var(--color-text-primary) 12%, transparent)` |
| Border-radius         | 2px                                                                         |
| Padding               | `--space-lg` (24px) all sides                                              |
| Display               | `flex; flex-direction: column; gap: --space-md (16px)`                     |
| Hover state           | Phase 3 scope (scroll reveal + hover transitions). Phase 2: no hover state on card |

**Card internal structure (top to bottom):**
1. Project title (`<h3>`) — `--font-size-heading` (1.5rem), Space Grotesk 600, `--color-text-primary`, margin 0
2. Card copy block (`<p>`) — 3 sentences (problem / highlight / outcome), Inter 400, 1rem, `--line-height-body` 1.6, `--color-text-primary`
3. Tech pills row (`.project-card__pills`) — inline-flex, flex-wrap, gap `--space-xs` (4px)
4. CTA button row (`.project-card__actions`) — margin-top: auto (pushes to card bottom)

**Tech Pill (`.pill`):**
- Font: Inter, `--font-size-label` (0.875rem / 14px), weight 400, `--color-text-secondary`
- Background: `color-mix(in srgb, var(--color-text-primary) 8%, transparent)` (warm near-transparent tint)
- Border: 1px solid `color-mix(in srgb, var(--color-text-primary) 15%, transparent)`
- Padding: `--space-xs` (4px) vertical, `--space-sm` (8px) horizontal
- Border-radius: 2px
- No interactivity (D-10)

**Marketplace Button (`.btn--outline`):**
- Single link: one full-width button spanning card width
- Two links (cross-engine card): `display: flex; gap: --space-sm (8px)` — both buttons equal width (`flex: 1`)
- Style: outlined — background transparent, border `1px solid --color-accent`, text `--color-accent`, font Inter 400 0.875rem
- Padding: `--space-sm` (8px) vertical, `--space-md` (16px) horizontal
- Min-height: 44px
- Border-radius: 2px
- Hover: background `color-mix(in srgb, var(--color-accent) 10%, transparent)`, border stays, transition 200ms ease
- Attribute: `target="_blank" rel="noopener noreferrer"` (external links)
- Icon: none (text-only CTA, consistent with no-icon-library rule)

## JS Module Contract

**`js/projects.js`** — new ES module, added as `<script type="module" src="js/projects.js"></script>` at end of `<body>`.

Responsibilities:
1. `fetch('data/projects.json')` — relative path (works on both localhost and GitHub Pages)
2. Parse JSON array
3. For each project: create `.project-card` DOM element using the card structure above and inject into `#projects`
4. Error handling: on fetch failure or parse error, render the error state copy defined in Copywriting Contract
5. No external dependencies — vanilla JS only
6. No mutation of existing DOM outside `#projects`

Injection pattern: build cards into a `DocumentFragment` then append once (single DOM write).
