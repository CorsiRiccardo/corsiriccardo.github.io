Append the following CSS block INSIDE that block — inserted immediately before the closing `}` on line 125. Do NOT open a second `@layer components { }` block anywhere in the file.

Append this exact block:

```css

  /* ===== Phase 2: Hero ===== */
  /* ID selector beats layout.css section { min-height: 200px } across the layer boundary */
  #hero {
    min-height: calc(100vh - var(--nav-height));
    display: flex;

  .hero__subtitle {
    font-family: var(--font-family-display);

  .btn--primary {
    background-color: var(--color-accent);
    color: #ffffff;
    border-color: var(--color-accent);
    margin-top: var(--space-xl);
  }

  .btn--primary:hover {
    opacity: 0.85;
    transform: translateY(-1px);
  }

    background-color: transparent;

      transition: none;
    }

      transform: none;
    }
  }
```

Constraints:
- `#hero` uses the ID selector — this is intentional. It beats `section { min-height: 200px }` in `@layer layout` across the cascade layer boundary.
- `color: #ffffff` on `.btn--primary` is the only permitted raw hex value. It is a fixed white text color on the amber accent background. The UI-SPEC confirms this meets WCAG AA contrast (4.6:1).
- The `rgba()` line on `.btn--outline:hover` is a required fallback — write it on the line immediately before the `color-mix()` override.
- `@media (prefers-reduced-motion: reduce)` block is mandatory — removes `transition` and `transform` on hover.
- No second `@layer components { }` block. Count must remain 1.
