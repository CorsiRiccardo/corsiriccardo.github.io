**css/layout.css** — Mobile-first page grid. CRITICAL: never use overflow: hidden on html element (breaks position: sticky). Use overflow-x: hidden only on body, never on html:
```css
@layer layout {
  body {
    /* prevent horizontal overflow — on body only, NOT html (html overflow:hidden breaks sticky) */
    overflow-x: hidden;
  }

  main {
    max-width: var(--max-width);
    margin-inline: auto;
    padding-inline: var(--space-xl); /* 32px on mobile */
  }

  section {
    padding-block: var(--space-2xl); /* 48px top/bottom on mobile */
    min-height: 200px; /* Phase 1 shell — sections are empty placeholders */
  }

  footer {
    background-color: var(--color-bg-secondary);
    padding-block: var(--space-lg);
    padding-inline: var(--space-xl);
  }

  /* Tablet and up */
  @media (min-width: 768px) {
    main {
      padding-inline: var(--space-2xl); /* 48px */
    }
  }

  /* Desktop */
  @media (min-width: 1024px) {
    main {
      padding-inline: var(--space-2xl);
    }

    section {
      padding-block: var(--space-3xl); /* 64px */
    }
  }
}
```
