# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Foundation & Shell.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> semantic HTML skeleton. No content sections are implemented in this phase —
> hero, projects, about, timeline, and contact are Phase 2 scope.

## Spacing Scale

Declared values (multiples of 4 — 8-point base scale):

| Token | Value | Usage                                      |
|-------|-------|--------------------------------------------|
| xs    | 4px   | Icon gaps, inline tag padding, hairline gaps |
| sm    | 8px   | Between inline elements, tight list gaps   |
| md    | 16px  | Default paragraph/element spacing          |
| lg    | 24px  | Nav item spacing, card inner padding       |
| xl    | 32px  | Section inner padding (mobile)             |
| 2xl   | 48px  | Section inner padding (tablet+)            |
| 3xl   | 64px  | Between major page sections (desktop)      |
| 4xl   | 96px  | Vertical breathing room between sections (wide) — extended token, intentional; wide-viewport section gaps only, not part of the core 8-point sequence |

Exceptions:
- Touch targets for nav links: minimum 44px height (WCAG 2.5.5 AAA, applied as min-height/padding, not a spacing token)
- Body max-width: 1200px centered with auto horizontal margins

## Typography

All sizes in `rem` with `px` reference. Base: `1rem = 16px` (browser default, not overridden).

| Role    | Size         | Weight        | Line Height | Font              | Usage                             |
|---------|--------------|---------------|-------------|-------------------|-----------------------------------|
| Body    | 1rem (16px)  | 400 (regular) | 1.6         | Lora              | Paragraphs, nav labels, meta copy |
| Label   | 0.875rem (14px) | 400 (regular) | 1.4        | Lora              | Tech tags, captions, footer text  |
| Heading | 1.5rem (24px) | 600 (semibold) | 1.3        | Cormorant Garamond | Section headings (h2)             |
| Display | 3rem (48px)  | 400 (regular) | 1.1         | Cormorant Garamond | Page-level display (h1, hero name) |

Notes:
- Exactly 2 distinct weight values: 400 (Lora regular + Cormorant regular) and 600 (Cormorant semibold for h2 headings)
- Body and Label are distinguished by size (16px vs 14px) and color (text-primary `#2C2416` vs text-secondary `#6B5D4F`) — a third weight is not needed
- Cormorant Garamond at weight 400 already reads as a strong display face — semibold is reserved for h2 only, not h1
- Body line-height 1.6 chosen over 1.5 because Lora's calligraphic letterforms benefit from extra leading
- Display size 48px is the Phase 1 token declaration; exact hero usage is Phase 2 scope
- `font-display: swap` required on all `@font-face` declarations (FOUND-02)

Source: REQUIREMENTS.md FOUND-02, research SUMMARY.md Key Stack Decisions.

## Color

Palette: carta invecchiata (aged paper) — warm cream, warm brown ink, muted amber accent.

| Role            | Value     | Usage                                                      |
|-----------------|-----------|------------------------------------------------------------|
| Dominant (60%)  | `#F5F0E8` | Page background (`body`), primary surface                  |
| Secondary (30%) | `#EDE8DF` | Nav background (sticky state), `<footer>` background, subtle section dividers |
| Text primary    | `#2C2416` | All body text, headings, nav labels — warm near-black       |
| Text secondary  | `#6B5D4F` | Captions, label text, meta information, footer copy        |
| Accent (10%)    | `#8B6914` | Reserved for: nav active-link indicator, external link underlines only |
| Destructive     | n/a       | No destructive actions in Phase 1 or this site at all      |

Accent reserved for: nav active-link state, anchor `<a>` underline on hover. Never used as a fill or background color.

Paper texture overlay (FOUND-03):
- Implemented as `body::before` with a pre-rendered 200×200px PNG noise tile
- `position: fixed; inset: 0; z-index: 9999; pointer-events: none`
- `opacity: 0.035` — invisible without scrutiny, present on close inspection
- Tile is seamlessly tileable via `background-repeat: repeat`
- PNG filename: `assets/textures/paper-grain.png` (lowercase, per LAYOUT-04)

WCAG AA compliance (FOUND-04):
- Text primary `#2C2416` on dominant `#F5F0E8`: contrast ratio ~12:1 (passes AAA)
- Text secondary `#6B5D4F` on dominant `#F5F0E8`: contrast ratio ~5.5:1 (passes AA)
- After texture overlay at opacity 0.035 the effective background lightens by < 0.5% — contrast ratios remain valid
- All contrast pairs must be re-verified in Phase 4 implementation with actual texture applied

Source: REQUIREMENTS.md FOUND-01, FOUND-03, FOUND-04, research SUMMARY.md Pitfalls #4.

## CSS Architecture

Declared `@layer` order (FOUND-05):

```
@layer tokens, reset, base, layout, components, animations;
```

File split:
| File                  | Layer(s)           | Contents                                  |
|-----------------------|--------------------|-------------------------------------------|
| `css/tokens.css`      | tokens             | All custom properties (colors, spacing, type scale, z-index) |
| `css/reset.css`       | reset              | Box-sizing, margin/padding zero, list reset |
| `css/base.css`        | base               | `body` styles, `a` defaults, heading defaults, font-face declarations |
| `css/layout.css`      | layout             | Page grid, section widths, nav positioning |
| `css/components.css`  | components         | Nav, footer — Phase 1 shell components only |
| `css/animations.css`  | animations         | Phase 3 scope — file created empty in Phase 1 to establish the layer |

All custom property names follow `--color-*`, `--space-*`, `--font-size-*`, `--font-weight-*` naming convention.

Source: REQUIREMENTS.md FOUND-05, CLAUDE.md stack decisions.

## Navigation Contract

Applies to: sticky `<nav>` inside `<header>` (LAYOUT-02).

| Property        | Value                                               |
|-----------------|-----------------------------------------------------|
| Position        | `position: sticky; top: 0`                          |
| Background      | `#EDE8DF` (secondary color) at 95% opacity with `backdrop-filter: blur(4px)` on supported browsers |
| Height          | 64px (matches `--space-4xl` token, aligns to 8-pt grid) |
| Nav link color  | Text primary `#2C2416`                              |
| Active link     | Accent `#8B6914` underline, 2px, animated with CSS `transition: border-color 200ms ease` |
| Link font       | Lora 400, 14px (label size)                         |
| Z-index         | `z-index: 100` (tokens layer declares this)         |
| Mobile breakpoint | Hamburger at < 640px; links stack vertically in disclosed panel |

Active-link detection: second Intersection Observer on section entry/exit — toggles `.nav-link--active` class. No inline styles, no JS color assignment.

Source: REQUIREMENTS.md LAYOUT-02, LAYOUT-03.

## Asset Filename Convention

All asset paths must be lowercase with hyphens (LAYOUT-04, GitHub Pages is case-sensitive Linux):

| Asset type   | Path pattern                    |
|--------------|---------------------------------|
| Fonts        | `assets/fonts/*.woff2`         |
| Texture      | `assets/textures/paper-grain.png` |
| OG image     | `assets/og-image.png`           |
| Favicon      | `assets/favicon.ico` + `assets/favicon.svg` |

No uppercase letters, no spaces, no camelCase in any filename or directory name.

## Responsive Breakpoints

Mobile-first. Breakpoints declared as custom properties and used in media queries:

| Breakpoint | Value  | Behavior change                               |
|------------|--------|-----------------------------------------------|
| sm         | 640px  | Nav collapses to hamburger below this         |
| md         | 768px  | Two-column layouts become available           |
| lg         | 1024px | Max-width container activates                 |
| xl         | 1200px | Max-width cap (body never exceeds this)       |

Declared as `--breakpoint-sm` etc. in `tokens.css` as documentation comments only — CSS media queries reference the raw values (custom properties cannot be used inside `@media`).
